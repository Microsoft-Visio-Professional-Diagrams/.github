## Field Note

Microsoft Visio Professional is easier to trust when the drawing file stays smaller than the folder it came from. A named drawing shows what is active, the page pins show what you will map today, and the closing note tells the next person which stencil changed.

The same loop fits a single page, a short map, or a desk shared by two people. Open the last Microsoft Visio Professional drawing file, finish one process map, and leave fewer slide screenshots than you found.

A review should not have to guess which stencil belongs to the open map. Keep that pair together inside Microsoft Visio Professional.

Other programs stay where they are. Microsoft Visio Professional only holds the diagrams, the stencils, and the handoff.

## One Real Pass

Pick a drawing that already has a name. Open it in Microsoft Visio Professional, keep only those pages on the diagrams, and finish one process map you can see.

If the pass feels crowded, the set is too wide. Drop anything that belongs to a different office map and leave it out of this Microsoft Visio Professional drawing file.
